# SDMon Beta 01 Windows Backlog

This backlog records known Windows Beta 01 polish and validation items that should not block Phase 3 collector implementation.

## Backlog Items

- Browser extension names may still show `__MSG_xxx` localization placeholders.
- Security findings need stronger raw evidence display.
- Firewall, UAC, and BitLocker detection accuracy need later validation across Windows versions and editions.
- HTML and PDF report layout can be improved later.
- Findings may need allowlist and tuning support.
- False positive review is required after broader endpoint testing.
- Cross-version Windows testing is needed for Windows 10, Windows 11, Windows Server, PowerShell 5.1, and PowerShell 7.
